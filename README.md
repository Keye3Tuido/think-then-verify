# Think-Then-Verify

TV 是一份持续对齐目标、约束与证据的 agent 流程文档。完整要求在 [AGENTS.md](AGENTS.md)，按对齐主线、核对行动、核验结果、核验交付的循环执行；任务依据在上下文恢复与局部工作完成后持续保留。

## 审阅

应用前核验目标保持、约束遵守、结果真实性与交付质量；确认流程适用于当前使用方式后，再安装到实际生效的指导入口。

## 安装

备份目标文件，只替换 `think-then-verify` 的完整标记区块；没有区块时追加，保留其他用户规则。标记残缺、重复或规则冲突时先查明。已有全局规则覆盖当前项目时复用。

直接安装完整正文，保留宿主要求的文件名和元信息。流程依赖宿主实际加载指导文件并由 AI 执行，不使用 Hook、适配器、启停状态或技能调用入口。

## 核验范围

审阅时检查：上下文恢复能找回主线，追问不丢失原任务，动作前遵守约束和授权，失败后核查副作用，局部成功不冒称整体完成，无进展时停止重复，交付说明真实结果和必要缺口。

文件安装、宿主加载和实际行为分别核验。文件写入或文本检查不能证明模型必定遵循流程。
