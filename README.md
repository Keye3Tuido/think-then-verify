# Think-Then-Verify 1.0.0

TV 是一份用于持续对齐任务的 agent 文档。固定流程为：对齐目标 → 核对行动 → 执行并核验 → 回到主线 → 检查交付。在长上下文、局部工作完成和需求补充后恢复整体目标与核心约束，依据真实结果推进；无法在规则内完成时明确说明原因。日常检查静默进行，交付只保留有用信息。

## 安装

完整流程在 [AGENTS.md](AGENTS.md)，可单独使用。将其中 `think-then-verify` 标记区块合并到当前 AI 实际加载的全局或项目指令文件，保留其他规则。全局规则已覆盖当前项目时复用。

可选安装器会备份已有文件，只替换对应区块；重复安装保持一份规则，标记残缺或重复时保留原文件并报错。

```bash
python3 install.py check --agents-file /path/to/AGENTS.md
python3 install.py install --agents-file /path/to/AGENTS.md
```

`--source /path/to/TV-AGENTS.md` 可指定流程文件。目标位置由宿主实际指令入口决定，不绑定任何 agent 软件。同包的 SKILL.md 仅供现有技能目录发现、检查和安装这份文档；自动执行使用已安装的完整流程。

流程持续适用，没有启停命令或会话开关，也不使用 Hook、适配器和消息续跑。安装完成后须确认宿主会加载目标文件；指令约束依赖 AI 遵循，不是程序强制拦截。

## 升级

从旧版本迁移时，先备份并移除本系统的 Hook 注册及信任状态，重新加载宿主并确认旧回调停止后，再删除旧运行时；混合配置只删除本系统部分，保留其他策略。用当前 AGENTS.md 替换旧标记区块，移除旧启停约定。历史任务记录可留作核查。

## 验证

```bash
python3 test_install.py -q
```

安装测试覆盖独立流程文件、通用目标、重复安装、升级替换、用户规则保留及错误标记保护。实际行为应结合任务核验：恢复后继续原目标，局部成功不冒称整体完成，规则优先，失败后先检查副作用，输出说明真实结果和必要缺口。安装测试不能代替宿主加载和模型行为验证。
