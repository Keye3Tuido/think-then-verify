# Think-Then-Verify

TV 是持续保持任务主线、遵守约束并依据证据行动的 agent 指导文档。完整流程位于 [AGENTS.md](AGENTS.md)。

## 流程

保留目标、约束、证据和待办。Think 形成行动或答复候选，Verify 检查候选及依据，Decide 选择执行、补证、修正、提问或停止。行动执行后核验真实结果并返回主线，答复核验通过后由 Output 交付。

流程在当前工作中静默执行。复杂任务按进展循环，条件未变时复用有效核验；无实质进展时停止重复。强制规则与授权边界优先于目标。

## 安装

确认流程后，将完整 `think-then-verify` 标记区块合并到宿主实际加载的全局或项目指导文件。修改前备份，只替换本区块，保留其他规则及宿主元信息；标记残缺、重复或规则冲突时先查明。已有全局规则覆盖当前项目时复用。

流程由宿主加载正文后通过 AI 执行，不使用 Hook、适配器、启停状态或技能调用入口。仅保存文件不能证明宿主已加载，也不能证明模型必定遵循。

## 核验范围

按实际行为检查：恢复后保留原任务，状态追问不清空待办，操作前满足约束和授权，缺少证据时按需要调查或说明未知，失败后检查副作用，局部测试不冒称整体验收，通过修正返回核验，无进展时停止重复，交付提供读者需要的结果与边界。
